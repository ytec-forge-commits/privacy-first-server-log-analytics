# Security / セキュリティ

## English

Please do not open a public issue for a suspected vulnerability. Report it privately to the repository owner with the affected version, reproduction steps, impact, and a safe proof of concept. Do not include production logs, IP addresses, credentials, or other personal data.

Supported releases receive fixes on the default branch. Before deploying an update, back up the private SQLite database locally, verify its hash, and test the import with a synthetic log.

## 日本語

脆弱性の可能性は公開Issueに投稿せず、リポジトリ所有者へ非公開で連絡してください。対象バージョン、再現手順、影響、安全なPoCを添え、実運用ログ・IPアドレス・認証情報などの個人情報は含めないでください。

対応版は既定ブランチで修正します。更新前にはprivate領域のSQLite DBをローカルへバックアップし、ハッシュを確認してから、合成ログで取込を試験してください。
