# プライバシーモデル

[English](privacy-model.en.md)

## 目的

このアプリケーションは、サーバーが通常の運用で出力するアクセスログから、サイト改善に必要な最小限の**集計値**だけを作ります。ブラウザに新たな追跡処理を追加しません。

## 保存するもの

- 日付または月
- PV、通常アクセス、既知Bot、HTTP状態、404の安全な種類
- 公開ルート一覧にあるページの識別子
- 管理者が明示的に許可した外部Referrerドメイン、Direct、内部という分類
- ブラウザ名、OS名、PC／スマホ／その他という分類
- 取込ファイル名、SHA-256、取込日時、件数

## 保存しないもの

- IPアドレス
- User-Agent原文
- 完全なReferrer URL
- Query String
- 個別リクエスト、訪問者ID、Cookie識別子、フィンガープリント
- 生ログの複製、訪問者数、セッション数
- 未知404のURL

日次集計は既定で90日、月次集計は24か月で削除します。保持期間を変更する場合は、公開しているプライバシー説明にも同時に反映してください。

`referrer_domains` は、保存してよい外部ドメインの許可リストです。許可していない外部Referrerはホスト名を保存せず、`external:other` にまとめます。識別子をサブドメインへ埋め込める任意サイトの値を保存しないためです。

## 境界

この配布物にはブラウザBeaconや任意Payloadを受け取る公開APIはありません。将来、ダウンロードや外部遷移などを測る必要があっても、既存サーバーログまたは既存サーバー処理で確認できる事実だけを集計対象にしてください。
